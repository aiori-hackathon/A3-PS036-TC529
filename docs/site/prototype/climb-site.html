Architecture

A Rust workspace links OpenSSL, liboqs and libMTL, benchmarks with Criterion, and captures live DNS from patched NSD and Unbound in Docker.

Transparency

Nothing on this page is typed in by hand. Each number is read from a recorded artifact and checked against a claims registry.

Reproducible datasets

Deterministic datasets in three sizes and repeated trials. One command, cargo xtask reproduce, rebuilds the artifact chain.

Pinned and fingerprinted

liboqs and libMTL are pinned submodules. environment.json records CPU, kernel and toolchain.

Claims registry

Each claim stores its JSON pointer, expected value and pass or fail mark. The README badge reports 771 of 771 verified.

Known experimental limits

Results are empirical. No formal security guarantee, proof or certification is claimed for MTL mode, SLH-DSA or any component. They cover one parameter set (SLH-DSA-SHA2-128s-MTL-SHA2-128), one reference implementation and one laptop-class machine. Native SLH-DSA is not SIMD-tuned in the pinned build. The DNS pipeline runs locally only.
